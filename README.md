# Solomon Ashagre — Personal Portfolio

A single-page personal portfolio website built with plain HTML and CSS.
This is my first task for my remote internship at **Synent Technologies**.

## Live Demo

https://sol-personal-portfolio.vercel.app

## About

The site introduces me as a MERN Stack Developer and Tech Educator based
in Addis Ababa, Ethiopia, and includes:

- **Header** — name and title
- **About Me** — short bio
- **Skills** — languages, stack & tools, professional skills
- **Experience** — internship, teaching, and tutoring roles
- **Education** — degree and school history
- **Contact** — phone, email, GitHub, LinkedIn, Instagram

## Tech Stack

- HTML5
- CSS3 (custom properties, CSS Grid, Flexbox)
- [Google Fonts](https://fonts.google.com/) — Fraunces & Inter

No build tools, frameworks, or dependencies — it's a static site that
runs directly in the browser.

## Project Structure

```
.
├── index.html      # Page markup and embedded styles
├── favicon.svg      # Site favicon (monogram)
└── README.md         # This file
```

## Running Locally

Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
open index.html   # macOS
# or just double-click index.html on Windows/Linux
```

No server or build step is required.

## Deployment

This project is deployed on [Vercel](https://vercel.com) as a static site,
connected to this GitHub repository. Every push to `main` triggers a new
deployment automatically.
